# Изменения

Версии по [semver](https://semver.org/lang/ru/).

## 0.3.0

- zapret2 (bol-van/zapret2) — второй движок рядом с Flowseal: папка в настройках с проверкой версии и
  совместимости Lua, две встроенные стратегии, свои стратегии в текстовом редакторе с проверкой
  `winws2 --dry-run` и `--intercept=0`, служба `zapret2` в один клик, переключение движков, смешанные прогоны
  тестов. Команды CLI `zapret2 info|validate|save|delete`; папку zapret2, как и папку Flowseal, меняют только в окне.

## 0.2.0

- `zapret-hub-cli.exe` — командная строка для ИИ-агентов и скриптов: все действия окна, кроме чисто оконных и смены папки zapret,
  ожидание прогона тестов с компактным рейтингом, запуск приложения через задачу автозапуска. Вывод — JSON,
  коды выхода постоянные. Включается флажком «Управление из командной строки» в настройках, по умолчанию
  выключено. Руководство — `cli.md` в архиве.

## 0.1.0

Первая версия.

- Управление Flowseal zapret-discord-youtube вместо `service.bat`: служба, стратегии, игровой фильтр, ipset,
  фейки, свои списки, обновление ipset и hosts, системные проверки, очистка кэша Discord.
- Свои стратегии: копия оригинальной, редактор блоков, проверка `winws --dry-run`.
- Тесты стратегий: стандартный набор `test zapret.ps1` и DPI 16–20, рейтинг, история, копирование результатов.
- Трей с быстрой проверкой раз в 30 минут, уведомления Windows, автозапуск через Планировщик.
- Снимок состояния перед каждой изменяющей операцией: откат при ошибке и восстановление после аварийного
  завершения.
