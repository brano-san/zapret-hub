# Изменения

Версии по [semver](https://semver.org/lang/ru/).

## 0.9.1

- Linux: маршрутизация через SOCKS5-прокси. Правила `routes.toml` (протокол, порты, подсети, домены, программы)
  работают как на Windows через nftables (`redirect` для TCP, TPROXY для UDP) и чтение ответов DNS; та же вкладка
  «Маршруты», команды `router`/`routes`, счётчики и потоки. Нужны права `CAP_NET_ADMIN` и `CAP_NET_RAW`: кнопка
  «Разрешить маршрутизацию» или `zapret-hub-cli routes grant` выдаёт их через `setcap` программе `zapret-hub-cli`
  и оставляет запуск её и хаба только вам (`root:<ваша группа>`, `0750`); хаб запускает себя через неё и получает
  права как наследуемые, поэтому трей и уведомления работают и с ними. Действуют после перезапуска, после
  обновления — снова. Только IPv4; правила по доменам не видят DNS over TLS/HTTPS. Таблица
  и правила `ip` убираются при выключении, выходе и сигналах завершения, а после падения — при следующем
  запуске. Для правила `ip rule` хаб берёт свободную таблицу маршрутов (23112 или следующую) и свободный приоритет,
  чужие таблицы не трогает. Пункт «Маршрутизация» в трее теперь и на Linux. Подробности — `docs/linux.md`.
- Тесты: «Выбрать всё» и `tests run` без имён берут и встроенные копии стратегий Flowseal — после ухода
  Flowseal это основной набор.
- Диагностика больше не читает журнал, маршруты и конфиг прокси-клиента: убраны его папка в настройках
  (ключ CLI тоже), паттерны «домен через системный прокси» и «медленный DNS прокси» и вердикт `proxy_broken`.
  Соединения через системный прокси диагностика отмечает как неразобранные. Подсказка адреса SOCKS5 проверяет
  только порты 2080, 10808 и 7890. Старые настройки и отчёты загружаются.
- Linux: если в папку `XDG_RUNTIME_DIR` могут войти другие (WSLg: `0755`), сокет CLI лежит в
  `/tmp/zapret-hub-<uid>/`; раньше CLI там не работал.

## 0.9.0

- Linux: хаб работает на Linux x86_64 (nfqws2, nftables, systemd, трей через AppIndicator, автозапуск через
  XDG, Unix-сокет для CLI, пути XDG). Порт начал [Mai-kun](https://github.com/Mai-kun)
  ([Mai-kun/zapret-hub-linux](https://github.com/Mai-kun/zapret-hub-linux)). Установка, устройство и ограничения —
  в `docs/linux.md`. Маршрутизация SOCKS5 и наблюдение за потоками в диагностике только на Windows.
- Движок Flowseal убран: вкладки, стратегии, службу `zapret` и команды CLI заменил zapret2. Настройки 0.8.0
  переносятся автоматически при первом запуске, встроенные стратегии zapret2 включают копии стратегий
  Flowseal 1.10.3. Службу `zapret` Flowseal заменяет на `zapret2` разовый переход при первом запуске, иначе её
  предлагает удалить системная проверка; применение стратегии её не трогает. Рейтинг тестов 0.8.0 указывает на
  копии стратегий в zapret2 («Применить лучшую», трей).
- Интерфейс: новый обзор с баннером состояния, вкладка «Инструменты» (бывшая «Zapret»: служба, TG WS Proxy,
  монитор nftables и журнал на Linux), стратегии с фильтром по технике и сводкой по сервисам, колонки Steam и Epic в
  тестах, поиск zapret2 в настройках, предупреждение о несохранённых правках.
- TG WS Proxy: локальный MTProto-прокси tg-ws-proxy-rs скачивается из хаба (проверка SHA-256), работает как
  дочерний процесс на Windows и пользовательский юнит systemd на Linux; команды `tg-ws`.
- Тесты: цели проверяются разом, DbD без TLS 1.3, отдельные оценки Steam, Epic и DbD, в истории последние
  50 прогонов (результаты старых прогонов по Steam и Epic пусты).
- Пресеты маршрутов `cloudflare`, `telegram`, `twitch`. Встроенные стратегии берут UDP голоса Discord до
  порта 65535.
- Исключения: домены, подсети и порты (`exclusions`); порты — для таблицы nft на Linux.
- CLI: `probe` (DNS, списки, маршрут и живая проверка домена или адреса), `service`, `nft`, `dns-flush`,
  `exclusions`, `tg-ws`.

## 0.8.0

- Диагностика: вкладка «Диагностика» и команды `diag` наблюдают за программой или профилем (Discord, Dead by Daylight,
  YouTube, любая программа), находят адреса, которые не открываются, перебирают пути (напрямую, zapret и zapret2 со
  стратегиями, прокси точечно, прокси вместе со zapret), объясняют причину и дают кнопку «Применить». Режимы «сам» и
  «со мной». Всё откатывается при отмене, ошибке и падении хаба.
- Стратегия `hub-circular` (zapret2): хаб собирает circular из найденных приёмов.
- UDP в circular: UDP-профиль получает детектор по счёту пакетов (`udp_out=4:udp_in=1`, `--out-range=-n4`,
  `--in-range=-n2`), порты расширяют `--wf-udp-*`.
- Протокол CLI с приложением стал версии 5: обновите CLI и приложение вместе.

## 0.7.0

- Встроенные стратегии zapret2: 22 копии стратегий Flowseal 1.10.3 (`zapret2:general (ALT5)` и т.д.,
  `general.bat` — `zapret2:general (Flowseal)`). В прогон тестов по умолчанию не входят; клон копии называется
  `ALT5 copy`.
- Предупреждение на вкладке маршрутов, когда Windows шифрует DNS и доменные правила не видят имён.
- Протокол CLI с приложением стал версии 4: обновите CLI и приложение вместе.
- В `list-general-user.txt` хаб сам дописывает свой набор доменов (AWS, X/Twitter, Cloudflare, серверы и сайт DbD, NuGet),
  если их там нет; удалённый домен из набора вернётся при следующем запуске.

## 0.5.0

- Маршрутизация TCP и правила по доменам (этап 2): TCP перенаправляется в локальный приёмник хаба и идёт к прокси
  через `CONNECT`; домены узнаются из ответов DNS (в правилах поле `domains`, протокол `tcp`/`udp`/`both`).
  Профиль «Discord целиком», домен `discord.media` в «Discord голос», импорт доменов из `.txt`, колонка «Домен» в
  потоках, подсказка про «безопасный DNS». Windows может спросить про брандмауэр для `zapret-hub.exe`.
  Пауза и выключение обрывают перенаправленные TCP-соединения.
- Протокол CLI с приложением стал версии 2: `zapret-hub-cli.exe` версии 0.4 получит отказ «protocol v1 is not
  supported», обновите CLI и приложение вместе.

## 0.4.0

- Маршрутизация UDP через локальный SOCKS5 (этап 1): выбранный UDP-трафик (подсети IPv4 и порты из
  `data\routes.toml`) идёт через прокси прямо из процесса хаба, без TUN и без окна PowerShell. Правила,
  вкладка «Маршруты» (правила, редактор, потоки), пункт «Маршрутизация: вкл/выкл» в трее, команды CLI `router` и `routes`.
  Профиль «Discord голос» заменяет `discord-udp-proxy.ps1`. Прокси недоступен — трафик идёт напрямую.
  На время тестов стратегий маршрутизация встаёт на паузу и потом возобновляется.

## 0.3.0

- «Скачать последний релиз…» в мастере и в настройках: последний релиз Flowseal или zapret2 с GitHub через
  `curl.exe`, в новую папку, с ходом загрузки и отменой; zapret2 сверяется с `sha256sum.txt`, у Flowseal
  показывается SHA-256 архива. Блокировку Защитником Windows приложение распознаёт и объясняет. Только в окне.
- zapret2 (bol-van/zapret2) — второй движок рядом с Flowseal: папка в настройках с проверкой версии и
  совместимости Lua, две встроенные стратегии, свои стратегии в текстовом редакторе с проверкой
  `winws2 --dry-run` и `--intercept=0`, служба `zapret2` в один клик, переключение движков, смешанные прогоны
  тестов. Команды CLI `zapret2 info|validate|save|delete`; папку zapret2, как и папку Flowseal, меняют только в окне.
- Для тех, кто пользуется только Flowseal: установка стратегии Flowseal и каждый прогон тестов завершают любой
  `winws2.exe` (в том числе запущенный вручную); «Удалить службу» и «Удалить службы» системной проверки могут
  удалить и службу `zapret2`.
- Мастер первого запуска спрашивает на первом шаге обе папки, zapret и zapret2; хватит одной. Приложение работает
  и с одним zapret2, без папки Flowseal: стратегии zapret2, служба, тесты и быстрая проверка (по встроенному
  списку целей); настройки Flowseal скрыты, его команды отвечают «choose the zapret folder in Settings».
  Встроенные стратегии zapret2 берут списки и фейки Flowseal и без его папки не запускаются.
- «Показать в проводнике» в карточке стратегии открывает папку её файла: `.bat` Flowseal (и своей) или `.txt`
  своей стратегии zapret2.
- Папки и ссылки открываются программой по умолчанию (например, сторонним файловым менеджером, назначенным для
  папок), без прав администратора — через рабочий стол Explorer; если его нет, как раньше через `explorer.exe`.
- Копия и новая стратегия сразу получают допустимое имя (`general ALT11 copy`), имя проверяется по мере ввода,
  «Сохранить» и «Клонировать» недоступны с неверным именем; ошибка имени от приложения показывается по-русски.
- «Копировать» (результаты теста, уведомление) на 1,5 с меняется на «Скопировано ✓», а если буфер обмена недоступен,
  пишет ошибку рядом.
- «Запустить тест» в результатах карточки стратегии запускает стандартный тест одной этой стратегии (Flowseal или
  zapret2) и открывает вкладку «Тесты»; пока идёт другой прогон, кнопка недоступна с объяснением.
- «Повторов» (1–5) у кнопки запуска тестов и у «Запустить тест» в карточке стратегии, `tests run --repeats N`
  в CLI: каждая стратегия проверяется N полными проходами по списку, рейтинг — по сумме ошибок и медиане
  задержек проходов, в таблице — разброс задержки между проходами, ход показывает «Проход k из N».
- Тесты изолированы строже: перед каждой стратегией не работает ни один `winws.exe`/`winws2.exe`, а прошлый
  процесс завершён и вышел (раньше `taskkill` не дожидался выхода); имена целей разрешаются до первой стратегии,
  временные метки TCP включаются, как при «Применить».

## 0.2.0
