# Стратегии Flowseal на zapret2: приёмка

> С версии после 0.8.0 движок Flowseal из хаба убран: стратегии Flowseal есть только как эти копии на zapret2, а их
> списки и фейки (1.10.3) встроены в приложение и лежат в папках `lists` и `bin` папки zapret2. Ниже — приёмка копий
> того времени, когда оригиналы ещё запускались.

Подпроект 8 (спецификация `docs/superpowers/specs/2026-10-17-zapret-hub-flowseal-zapret2-design.md`, раздел 4).
Каждая копия `zapret2:<имя>` прогнана тестом хаба через CLI в паре с оригиналом Flowseal 1.10.3 —
`zapret-hub-cli tests run --wait "<имя>" "zapret2:<имя>"`, стандартный набор (Discord, YouTube, DbD), у
пользователя, 2026-10-17. Пограничные пары повторены с `--repeats 3`; в таблице — последний прогон пары (ALT5 —
отдельный прогон вместе с двумя вариантами перевода).

**Правило приёмки (решение исполнителя).** Копия «не хуже», если по каждому профилю её `ok` не меньше, чем у
оригинала, минус 1 (разница в 1 — разброс между прогонами). Правило медианы «+20 %» из спецификации не
применяется: медиана одной и той же стратегии в соседних прогонах скачет между ~80 и ~300 мс (два кластера
серверов DbD и Discord), и сравнение медиан двух прогонов ничего не говорит о стратегии. Медианы — для справки.

## Что правилось

- `general (ALT11)`: ручной перенос пользователя расходился с `.bat` — выровнен по оригиналу.
- Все копии: трафик `ipset-all` остаётся в своём профиле, как в nfqws1 (профили без `--filter-l7`); фуллинг `ts`
  получает `:tcp_ts_up`.
- `general (ALT5)`: в первой серии хуже по DbD (13/27 против 16/27). Два других варианта перевода дали 14/27; в
  отдельном прогоне всех трёх копия — 16/27 против 13/27 у оригинала. Копия оставлена как есть: разница была
  разбросом.
